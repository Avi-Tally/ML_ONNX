# Changelog Template

**When to use this template**: summarizing release notes, pull requests, or version changes. Typical triggers: "summarize this release," "write changelog entry for PR #123."

Follow Keep a Changelog formatting conventions.

---

## Template

# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [vX.Y.Z] - YYYY-MM-DD

### Added
- Feature description with link to PR or issue (#123).

### Changed
- Refactored component behavior or updated default configs.

### Deprecated
- Features slated for removal in future releases.

### Fixed
- Bug fixes detailing exact symptoms resolved.

### Security
- Vulnerability patches or security updates.
