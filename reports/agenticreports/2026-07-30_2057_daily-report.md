## Accomplishments & Features Built

### 1. Decimal Parsing and Ageing Bucket Accumulation Fix
- **Summary**: Replaced raw `float()` parsing with safe `Decimal` parsing to prevent type mismatch errors during bucket aggregation (`float + Decimal` `TypeError`) and handled formatted currency strings with commas.
- **Touched Files**: `mcp_server.py`
- **Key Implementation Snippet**:
  ```python
  # mcp_server.py line 640-655
  for b in final_bills:
      age = b.get("age_days", 0)
      try:
          raw_amt = Decimal(str(b.get("amount", "0")).replace(",", "") or "0")
      except:
          raw_amt = 0.0
      amt = abs(raw_amt)

      # Find matching bucket
      for key, info in buckets.items():
          if age >= info["min"] and age <= info["max"]:
              if raw_amt < 0: # Dr
                  info["dr"] += float(amt)
              elif raw_amt > 0: # Cr
                  info["cr"] += float(amt)
              info["bills"].append(b)
              break
  ```
- **Rationale / Design Notes**: Converting `Decimal` amounts to `float` prior to adding to accumulated float totals (`info["dr"]`, `info["cr"]`) fixes runtime crashes while maintaining string-clean parsing for values containing thousand separators (`,`).
