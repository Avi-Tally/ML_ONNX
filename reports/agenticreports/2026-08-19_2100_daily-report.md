## Technical Decisions & Trade-offs

1. **Elimination of Multi-Request Socket Aggregation**:
   - Sequential requests over Tally's single-threaded HTTP XML server incurred quadratic latency overhead. Projections pushed down into TDL reduced latency by $>95\%$.
2. **Deterministic Pre-Classification Gating in NLP**:
   - Added regex and heuristic gates before ONNX inference in `nlp_engine.py` to prevent false positive classifications on explicit ledger balance queries (`"balance of <Party>"`).
